ToneForge Network Demo

Two browser windows, one host and one client. The host broadcasts behavioural events — never audio — and both windows resolve identical, deterministic sound sequences through the Demo 9 runtime.

Open this page in two windows. Add ?role=host to the first (or press Become host). The fingerprint in both windows must match after each transition.
Two-window manual run: npm run dev:web then open http://localhost:5173/network-demo.html?role=host and http://localhost:5173/network-demo.html.
